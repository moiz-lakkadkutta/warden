# B1 plan — console hardening (runlog/events.py, runlog/render.py, llm/cost.py)

## 1. Goal
`runs/<id>/events.jsonl` (+ `result.json`, `artifacts/pr_body.md`) replays into the ux-brief §2.4 page via
`warden console --run <id> --static`: header pill/cost/time/chips, duration-scaled timeline, branch tree, evidence table, per-phase log, footer.

## 2. Files to touch (exact public signatures)

### warden/llm/cost.py (changed)
- `CostCapExceededError.__init__(self, spent: float, cap: float, phase: str)` — unchanged signature; message becomes EXACTLY
  `f"cost cap ${cap:.2f} reached at {phase.capitalize()}; stopping. Raise with --max-usd"` (drop the "(spent …)" clause; keep `.spent/.cap/.phase` attrs).
- `CostMeter` gains optional field `log: EventLog | None = None` (last dataclass field, default None; import via `TYPE_CHECKING`-safe plain import —
  `runlog.events` imports only `schemas`, no cycle). `charge()`/`check()` unchanged signatures; when they raise and `log` is set, first emit
  `log.emit(phase, "cost_cap", {"spent_usd": spent, "cap_usd": cap})`. Existing call sites (`CostMeter(cap_usd=…)`) keep working.

### warden/runlog/events.py (changed)
- `EventLog.read(runs_dir, run_id) -> list[RunEvent]` unchanged. `EventLog.close()` becomes idempotent (safe to call twice).
- NEW `@staticmethod EventLog.read_result(runs_dir: Path, run_id: str) -> dict[str, Any] | None` — parses `result.json`, None if absent.
- NEW `def phase_spans(events: list[RunEvent]) -> dict[Phase, tuple[datetime, datetime]]` — per phase (first ts, last ts + last `ms`);
  phase with no events omitted. Module-level function (pure), used by render + tests.

### warden/runlog/render.py (rewritten; `render_run` signature kept)
- `PHASES`, `PHASE_COLOURS` unchanged. NEW verdict palette `VERDICT_COLOURS: dict[str, str]` (PASS/PASS WITH CONCERNS/FAIL/PENDING-HUMAN/COST CAP/RUNNING).
- NEW `@dataclass(frozen=True) Edge: parent: str; child: str; phase: Phase; shell: str; exit_code: int; ms: int`
- NEW `@dataclass(frozen=True) NodeRun: node: str; phase: Phase; shell: str; exit_code: int; ms: int` (keep=False runs: `to == from` or `to == ""`)
- NEW `@dataclass(frozen=True) BranchTree: base: str | None; candidate: str | None; theater: str | None; edges: tuple[Edge, ...]; runs: tuple[NodeRun, ...]`
  with `def children(self, node: str) -> list[str]` and `def test_run(self, node: str) -> NodeRun | None` (last run on node whose shell starts with "pytest").
- NEW `def build_tree(events: list[RunEvent]) -> BranchTree` (pure; see §3).
- NEW `def phase_durations_ms(events: list[RunEvent]) -> dict[Phase, int]` — from `phase_spans`; 0 for phases without events.
- NEW `def parse_evidence(md: str) -> tuple[str | None, list[tuple[str, str]]]` — (`**Verdict: X**` value, `[(check, result), …]` rows of the
  first `| Check | Result |` table). Pure; no HTML.
- NEW `def verdict_label(events, result, evidence_rows) -> str` — precedence: any `cost_cap` event → "COST CAP"; any pr-phase event with
  `data.label == "PENDING-HUMAN"` or a Risk-class row containing PENDING-HUMAN → "PENDING-HUMAN"; else `result["verdict"]` with `_`→space; else "RUNNING".
- NEW `def render_html(run_id: str, events: list[RunEvent], result: dict[str, Any] | None, evidence_md: str | None) -> str` — pure, returns the page.
- `def render_run(runs_dir: Path, run_id: str) -> Path` — unchanged; reads events/result/pr_body.md, calls `render_html`, writes `index.html`.
- Page sections (ids for tests/anchors): `#header` (pill `<span class="pill" data-verdict="…">`, `$total` = result cost_usd else Σ usd, total time =
  last ts − first ts, chips = distinct `data.model` of llm events else model names from the evidence Cost row), `#timeline` (5 `<a href="#phase-<p>">`
  bars, `style="flex-grow:<dur_ms+1>"`, cost on each), `#tree` (three nodes; edge cards `.edge.ok`/`.edge.fail`), `#evidence` (`<table>` from rows —
  same text as the PR body), `#log` (`<details open>` per phase; sandbox rows `shell → exit N · ms`; llm rows tokens + $), `#footer` (run_id,
  `warden resume <id>`, `<a href="events.jsonl">`). CSS includes `@media (max-width:600px){#tree{flex-direction:column}}`.

## 3. Branch tree derivation (from the demo's events.jsonl)
Demo emits, in order: fix `img-0001→img-0002` (copy_in test), fix `img-0002→img-0003` (copy_in service), verify `img-0001→img-0004` (theater copy_in),
verify `img-0004→img-0004 pytest … test_finalize_race.py exit 1`, verify `img-0003→img-0003 pytest -q backend/tests exit 0`.
- Edge = sandbox event with `to` non-empty and `to != from`. Run (NodeRun) = sandbox event with `to == from` or `to == ""` (Contree keep=False yields "").
- **base** = the first edge's `from` that never appears as any `to` (root). Demo: `img-0001`.
- **candidate** = `to` of the LAST fix-phase edge (the leaf of the fix lineage). Demo: `img-0003`. Never chosen by exit code — a failing candidate is still the candidate.
- **theater** = `to` of the first verify-phase edge whose `from` is base (theater_check forks base in phase verify). Demo: `img-0004`.
- Labels: candidate card green if `test_run(candidate).exit_code == 0`, text = evidence "Full suite on candidate" row if present ("214 passed, 0 failed") else
  `passed (exit 0)` / `failed (exit N)`. Theater card red-as-good if `test_run(theater).exit_code != 0`, text "failed on unfixed base — as required";
  if exit 0 → amber "passed on unfixed base — tests are theater". Missing node → grey "not run".
- Extra verify-phase edges from base (future best-of-N / race probes) render as additional plain cards; no crash on unknown shapes.

## 6. Risks / open questions
- "N passed" count is not in any sandbox event (box.py is forbidden; stdout not logged). Plan uses the evidence row as source of truth, exit code as
  fallback. If the orchestrator wants live counts before pr_body.md exists, box.py should add `stdout_tail` to the sandbox event (out of scope here).
- Model chips in the demo come from the evidence Cost row (no llm events in demo) — acceptable; live runs will have llm events.
- `console` CLI currently prints the path to stdout and `--run` maps to `run_id`; no cli.py change needed. `--static` is the default already.
- Contree `keep=False` returns `to == ""`; the FakeBackend returns `to == from`. Both are treated as node runs — tests cover both.
- Cost cap event requires `CostMeter(..., log=log)` to be wired in cli/client later (forbidden files now); without it behaviour is unchanged.
- Timeline bars in the demo are ~0 ms each → equal widths via `flex-grow:dur+1`; not a bug.
