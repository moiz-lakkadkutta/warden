## 2. Signatures (all in warden/integrate/pr.py)
- `PENDING_LABEL = "PENDING-HUMAN"` (exists; stays the single label constant).
- `def labels_for(plan: Plan) -> list[str]` → `[PENDING_LABEL] if plan.needs_human else []`. This is the
  C4 pass-through: C4 only adds a body reason; the label decision has one home.
- `@dataclass(frozen=True) class PrResult: url: str; argv: list[str]; exit_code: int`.
- `class PrOpenError(RuntimeError)`: attrs `fix: str`, `stderr_tail: str`; `str(err)` is the human
  sentence only (no "ERROR:" prefix). Caller prints sentence / fix / run_id per ux-brief §2.3.
- `Runner = Callable[..., subprocess.CompletedProcess[str]]` (called as
  `runner(argv, capture_output=True, text=True, check=False)`; default `subprocess.run`).
- `def open_draft_pr(repo: str, head: str, base: str, title: str, body: str, *, labels: list[str],
  runner: Runner = subprocess.run, log: EventLog | None = None) -> PrResult`.
  Body goes to a file: `log.artifact("pr_body.md", body)` when `log` is given (same artifact the
  console renders — single source of truth), else a `tempfile.NamedTemporaryFile(delete=False)` removed
  in `finally`. Emits `log.emit("pr", "tool", {"name": "gh", "args": argv[1:], "exit_code": rc,
  "url": url|None}, ms=elapsed)` whenever `log` is given, success or failure. Never imports typer.
- `def confirm_pr(yes: bool, *, what: str, run_id: str | None = None, input: TextIO = sys.stdin,
  err: TextIO = sys.stderr) -> bool`. `what` is the one-line description the caller composes
  ("owner/repo warden/201 → main · 'title' · PENDING-HUMAN"). Behaviour:
  1. `yes` → write `opening draft PR without asking (--yes)` to `err`, return True, read nothing.
  2. not `yes` and `not input.isatty()` → write three lines to `err`: `Not opening the draft PR: no
     terminal to ask on.` / `fix: re-run with --yes (CI), or run interactively.` / `run_id <id>` (when
     given); return False.
  3. TTY → write `Open draft PR? {what} [y/N] ` to `err`, read one line; `y`/`yes` (strip, casefold)
     → True; anything else or EOF → write `not opening the PR` and return False.
  Hand-rolled rather than `typer.confirm` because typer prompts on stdout, which would corrupt `--json`
  JSONL; stderr keeps stdout pure data.
- Demo path: **no prompt, no gh call, `--yes` accepted and ignored.** Justification: ux-brief §2.3 says
  the prompt exists for the one risky action, opening a PR; `--demo` opens nothing, so prompting would be
  a prompt for a non-action ("never prompt for anything else"); §2.6 requires the judge's `uvx warden run
  --demo` to run token-free and unattended; `tests/test_cli.py` runs it non-TTY under `--json`.
  demo.py stays untouched (forbidden file) — it already notes "draft PR body written" with the label.
- cli.py: **no edit required.** `run` already declares `--yes/-y` ("Open the PR without asking."). The
  live branch of `run` is still the Phase-B stub (exit 3), so the wiring point is documented for B6, not
  built now: after Verify, before `open_draft_pr`, `if not confirm_pr(yes, what=..., run_id=log.run_id):
  raise typer.Exit(2)`; on `PrOpenError e`: `_err(str(e)); _err(f"fix: {e.fix}"); _err(f"run_id ...")`,
  exit 1. The `result` line then carries `pr_url` (§5b). If the orchestrator wants the gate visibly wired
  in B5, the only acceptable edit is that snippet inside the live branch — it stays unreachable today.

## 3. Exact gh argv and URL parsing
`["gh", "pr", "create", "--draft", "--repo", repo, "--head", head, "--base", base, "--title", title,
"--body-file", path] + [tok for l in labels for tok in ("--label", l)]` — flags verified against
`gh 2.78.0` (`-R/--repo`, `-H/--head`, `-B/--base`, `-F/--body-file`, `-l/--label` repeatable). Long
flags only. gh prints the PR URL as the last stdout line (progress/warnings go to its stderr): parse with
`re.search(r"https://\S+/pull/\d+", completed.stdout)`; take the last match. Exit ≠ 0 →
`PrOpenError("gh could not open the draft PR for <head> on <repo> (exit N).", fix="check `gh auth
status` and that <head> is pushed; then re-run", stderr_tail=last 3 stderr lines)`. Exit 0 with no URL →
`PrOpenError("gh exited 0 but printed no PR URL.", fix="run the gh command from the run log by hand")`.
