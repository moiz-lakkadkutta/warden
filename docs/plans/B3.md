# B3-offline plan — fix/implementer.py: TDD loop over a scripted fake LLM

## 1. Goal
`run_implementer` drives Super through write-test → run → implement → run over the five TOOLS schemas + a `finish`
pseudo-tool, threads `ToolResult.box` through every call, enforces the tool-turn budget, "never delete a test"
and TDD order (warn-only), lets `CostCapExceededError` propagate, and returns a `Candidate` whose `image_uuid` is
the last checkpoint — exercised offline with `ScriptedLLM` over `FakeBackend`. Base = main 77ae6f9 (TOOLS + DX
merged). No existing signature changes; ui.py not imported (local `Progress` Protocol; `PhaseLog` satisfies it).

## 2. Rulings requested (orchestrator decides)
- Roles — DESIGN A (recommended): one loop on `Role.IMPLEMENTER` with `tools=ALL_TOOLS`; Super emits tool calls
  itself. `Role.TOOLS` (Lightning) runs ONLY when a Super turn is prose without tool calls: `chat(Role.TOOLS, "fix",
  [router system, prose as user], tools=ALL_TOOLS)` — native function calling; its `tool_calls` are spliced into
  Super's history as if Super made them. ALTERNATIVE B: every Super turn is prose, Lightning converts it each turn —
  2 calls per tool turn, whole files pass through Lightning (lossy) → rejected. `structured(ToolCall)` routing
  dropped: `LLMLike` stays `chat()`-only and every call has token counts.
- Stop protocol: `finish` tool (args = `FixReport`) intercepted, never dispatched. Alternative (trailing
  `structured(FixReport)` call) = one more model call + a second code path → rejected.
- "Never delete a test" applies to EVERY existing test-path file on the current box (tests_added ⊂ this).
  `prompt_hash` goes in a `note` emitted immediately BEFORE the first llm event (client.py owns the llm event's
  data and is forbidden; alternative later: an `extra` kwarg on `LLM.chat`).
## 3. Signatures (exact)
schemas.py (additive): `class FixReport(BaseModel)` (`extra="forbid"`): `done: bool` (desc "true when every
acceptance item passes; false when blocked"); `tests_added: list[str] = []`; `unmet: list[str] = []`; `notes: str = ""`.
fix/implementer.py:
- `@runtime_checkable class LLMLike(Protocol)`: `chat(self, role: Role, phase: Phase, messages: list[dict[str,
  Any]], *, tools: list[dict[str, Any]] | None = None) -> ChatResult` (ChatResult from warden.llm.client; light).
- `@runtime_checkable class Progress(Protocol)`: `step(self, text: str) -> None`, `cost(self, usd: float) -> None`
  (the caller, B6, calls `PhaseLog.phase("fix", …)` itself). `PROMPT_PATH: Path = Path(__file__).resolve()
  .parents[2] / "prompts" / "implementer.md"`; `prompt_hash(text: str) -> str` = sha256 hex[:12].
- `FINISH_TOOL: dict[str, Any]` = `{"type":"function","function":{"name":"finish","description":…,"parameters":
  tools._strict_schema(FixReport.model_json_schema())}}`; `ALL_TOOLS = [*TOOL_SCHEMAS, FINISH_TOOL]`.
- `is_test_path(path: str, plan: Plan) -> bool`: normalised path starts with `tests/`, contains `/tests/`, basename
  matches `test_*.py`/`*_test.py`, or is in normalised `plan.tests_to_add`. `removed_tests(before: str, after: str)
  -> list[str]`: names matching `^\s*(?:async\s+)?def\s+(test_\w+)` (MULTILINE) in `before`, absent in `after`.
- `build_messages(prompt_text: str, plan: Plan, max_tool_turns: int) -> list[dict[str, Any]]`: system = prompt +
  "## Available tools" (name — description) + "Budget: N tool turns"; user = issue, summary, files_to_touch,
  tests_to_add, landing_order, citations (url — claim), numbered acceptance.
- `assistant_message(content: str | None, tool_calls: list[dict[str, Any]]) -> dict[str, Any]`: OpenAI request
  shape `{"role":"assistant","content":…,"tool_calls":[{"id","type":"function","function":{"name","arguments":
  json.dumps(args)}}]}`; `tool_calls` omitted when empty.
- `run_implementer(llm: LLMLike, base: Box, plan: Plan, log: EventLog, *, dispatcher: ToolDispatcher | None =
  None, max_tool_turns: int, progress: Progress | None = None) -> Candidate`; None → `ToolDispatcher(log)`; phase "fix".
## 4. Loop ("turn" = one dispatched, refused, invalid-finish or unroutable model action)
1. Read PROMPT_PATH; `messages = build_messages(...)`; `box = base`; `turns = 0`; `tests_added = []`; `first_write
   = None`; `cost = 0.0`; `report = None`; `on_base: dict[str, bool] = {}`.
2. Note `{"implementer":"start","prompt_hash","issue","base": base.uuid,"max_tool_turns"}`.
3. While `report is None and turns < max_tool_turns`:
4.   `res = llm.chat(Role.IMPLEMENTER, "fix", messages, tools=ALL_TOOLS)` — no try/except anywhere in the module.
5.   `usd = usd_for(res.model, res.prompt_tokens, res.completion_tokens)`; `cost += usd`; `progress.cost(usd)`.
6.   `calls = res.tool_calls`; if empty and `res.content`: `routed = llm.chat(Role.TOOLS, …)` (§2), add cost, use its calls.
7.   `messages.append(assistant_message(res.content, calls))`.
8.   If `calls` empty: `turns += 1`; append user "Reply with a tool call (or finish)."; note unroutable; continue.
9.   For each call `(cid, name, args)` in order:
10.    if `turns >= max_tool_turns`: tool msg "tool budget exhausted; call finish" (not dispatched/counted); continue.
11.    if `name == "finish"`: valid `FixReport.model_validate(args)` → `report`, break; else `turns += 1`, tool msg
       "invalid arguments for finish:" + pydantic lines (no URLs).
12.    if `name == "write_file"` with str path/content and `is_test_path`: `before = box.run("cat <quoted>", keep=
       False)`; if ok and `removed_tests(...)`: `turns += 1`; tool msg "refused: write_file would delete test_x from
       <path>; add tests, never remove them"; note `{"refused_write","removed"}`; continue. Resolve `on_base[path]`
       once via `base.run("cat <quoted>", keep=False).ok`.
13.    `result = dispatcher.dispatch(box, name, args)`; `box = result.box`; `turns += 1`;
       `progress.step(f"{name} {path|command|''} → exit {code}")`; `messages.append(as_message(result, cid))`.
14.    if write_file ok: `first_write ??= path`; if test path and not on base → append to `tests_added` (dedupe).
15. After the loop: `report is None` → note `{"implementer":"budget","tool_turns"}` + progress.step. Then note
    `{"implementer":"tdd_order","first_write","test_first"}` (warn-only).
17. If `tests_added`: `r = box.run("pytest -q " + quoted paths, keep=False, timeout=600)`; note
    `{"implementer":"final_tests","tests","exit_code","tail": (stdout+stderr)[-500:]}`.
18. Note `{"implementer": "done"|"blocked","tool_turns","tests_added","cost_usd","image_uuid","report"}`; return
    `Candidate(issue=plan.issue, image_uuid=box.uuid, tool_turns=turns, tests_added, cost_usd=round(cost, 6))`.
Termination: each iteration sets `report` or raises `turns` ≥ 1 → ≤ max Super chats (+ ≤ 1 TOOLS call each).
## 5. Stop / abort matrix
| trigger | step | effect | event | result |
|---|---|---|---|---|
| `finish` valid | 11 | loop ends; rest of that turn's calls ignored | note done | Candidate |
| `finish` invalid | 11 | counted; errors fed back; continues | — | — |
| `turns == max` | 3/10 | no further chat; extra calls in the turn get the budget msg | note budget | Candidate, `tool_turns == max` |
| `CostCapExceededError` | 4/6 | propagates, never caught; no done note | cost_cap (meter) | raised |
| test-deleting write | 12 | refused, counted, box unchanged | note refused_write | continues |
| prose → Lightning | 6 | routed call dispatched normally | llm(tools) + tool | continues |
| prose twice / backend exception | 8 / 13 | counted + nudge appended / propagates (as tools, gate) | note unroutable / sandbox | continues / raised |
## 6. Fake LLM (tests/fakes.py) and fixtures
- `ScriptedLLM(turns: Sequence[ChatResult | BaseException], *, log: EventLog | None = None)`: `chat()` pops the
  next item (raises it if an exception; `AssertionError("script exhausted")` when empty → an extra call fails fast),
  deep-copies `messages` into `self.calls: list[Call(role, phase, messages, tools)]`, emits `log.emit("fix","llm",
  {"role","model","prompt_tokens","completion_tokens","tool_calls":[names]}, ms=0, usd=usd_for(...))` — the key
  set of `LLM._complete`, pinned literally in a test.
- Helpers: `tool_call(name, /, **args)` → `{"id": "call_N", "name", "arguments": args}` (the exact dict `_complete`
  builds); `turn(*calls, content=None, model="", pt=1000, ct=100)`; `text_turn(content)`; `finish_turn(done=True, …)`.
- `TddBackend(FakeBackend)`: `passes_after: dict[impl_path, test_path]`; overrides `run` so a `files=` write of an
  impl path sets `child.test_results[test_path] = 0` (writing the implementation makes the test pass) — fake.py
  untouched. `RecordingProgress`: lists `steps`, `costs`. Fixture `setup(log)`: `TddBackend({"src/fix.py": T})`,
  base `test_results = {T: 1}`, `Plan(issue=7, tests_to_add=[T], files_to_touch=["src/fix.py"], acceptance=
  ["test_fix passes"])`, `ToolDispatcher(log)`, `max_tool_turns=25` unless stated.
Scripts (T = tests/test_fix.py, `def test_a(): assert fix() == 1`): HAPPY: write T · run_shell `pytest -q
tests/test_fix.py` ("[exit 1]") · write src/fix.py · run_shell pytest ("[exit 0]") · finish(done=True,
tests_added=[T]). BUDGET: 25 × `read_file REF`, nothing after. BUDGET_MIDTURN: max=2; one turn with 3 × list_files.
COSTCAP: write T · run pytest · `CostCapExceededError(3.01, 3.0, "fix")`. REFUSE: write T (test_a+test_b) · write
T (test_b only) · finish(done=False, unmet=[…]). ROUTED: text_turn("let me list tests") · [TOOLS] turn(list_files
path="tests") · finish. UNROUTABLE: text_turn · [TOOLS] text_turn · finish. BADFINISH: turn(tool_call("finish",
done="maybe")) · finish. IMPL_FIRST: write src/fix.py · finish. EXISTING_TEST: base has tests/test_old.py
(test_z); write it with test_z+test_y.
